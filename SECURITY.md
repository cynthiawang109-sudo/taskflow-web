# Security policy

## Supported versions

Security fixes are applied to `main`. Older commits are not
patched; please use the latest `main` instead.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.
Use this repository's **Security** tab and choose **Report a
vulnerability** (GitHub private vulnerability reporting). Reports
are reviewed within a few days; confirmed issues are fixed on
`main` and, when they affect a release, published as a GitHub
security advisory.

## Scope

This is a portfolio demo frontend that runs only on fictional
data and talks to the TaskFlow demo API. Reports about this
app's own code, its dependencies, and its CI workflows are in
scope; findings that assume a production deployment do not
apply, because none exists.
